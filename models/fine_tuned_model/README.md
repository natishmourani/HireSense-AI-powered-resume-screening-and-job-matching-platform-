# SentenceTransformer based on sentence-transformers/all-MiniLM-L6-v2

This is a [sentence-transformers](https://www.SBERT.net) model finetuned from [sentence-transformers/all-MiniLM-L6-v2](https://huggingface.co/sentence-transformers/all-MiniLM-L6-v2). It maps sentences & paragraphs to a 384-dimensional dense vector space and can be used for retrieval.

## Model Details

### Model Description
- **Model Type:** Sentence Transformer
- **Base model:** [sentence-transformers/all-MiniLM-L6-v2](https://huggingface.co/sentence-transformers/all-MiniLM-L6-v2) <!-- at revision 1110a243fdf4706b3f48f1d95db1a4f5529b4d41 -->
- **Maximum Sequence Length:** 256 tokens
- **Output Dimensionality:** 384 dimensions
- **Similarity Function:** Cosine Similarity
- **Supported Modality:** Text

### Model Sources

- **Documentation:** [Sentence Transformers Documentation](https://sbert.net)

- **Hugging Face:** [Sentence Transformers on Hugging Face](https://huggingface.co/models?library=sentence-transformers)

### Full Model Architecture

```
SentenceTransformer(
  (0): Transformer({'transformer_task': 'feature-extraction', 'modality_config': {'text': {'method': 'forward', 'method_output_name': 'last_hidden_state'}}, 'module_output_name': 'token_embeddings', 'architecture': 'BertModel'})
  (1): Pooling({'embedding_dimension': 384, 'pooling_mode': 'mean', 'include_prompt': True})
  (2): Normalize({})
)
```

## Usage

### Direct Usage (Sentence Transformers)

First install the Sentence Transformers library:

```bash
pip install -U sentence-transformers
```
Then you can load this model and run inference.
```python
from sentence_transformers import SentenceTransformer

# Download from the 🤗 Hub
model = SentenceTransformer("sentence_transformers_model_id")
# Run inference
sentences = [
    'Job Title: Software Engineer - Category C\nRole: Software Engineer\nSkills: Postgres, Docker, Python3, MySQL, C#\nProjects: Looking for candidates who have experience in projects such as: Built a responsive web platform utilizing JavaScript (JS) and React on the frontend.\nEducation: Master of Science in Computer Science or equivalent technical experience.',
    'Resume of Candidate_60\nSkills: Java, Python, Data Structures, JS, AWS, PostgreSQL, SQL\nExperience: Software Engineer\nNetflix\nSeptember 2022 - August 2025\n- Designed and implemented major components.\n- Collaborated with cross-functional teams to deliver scale products.\nProjects: SoftwareEngineer 409\nDesigned and query-optimized an enterprise-scale relational database using PostgreSQL (Postgres).\n\nSoftwareEngineer 997\nDeveloped a distributed key-value store using C# and .NET with high throughput.\nEducation: Bachelor of Science in Information Technology\nIvy League University, 2023',
    'Resume of Candidate_19\nSkills: CI/CD, Linux, AWS, Prometheus, Kubernetes, Jenkins\nExperience: Lead DevOps Engineer\nGlobal Tech\nSeptember 2021 - December 2025\n- Designed and implemented major components.\n- Collaborated with cross-functional teams to deliver scale products.\n\nJunior DevOps Engineer\nGoogle\nJanuary 2022 - August 2025\n- Designed and implemented major components.\n- Collaborated with cross-functional teams to deliver scale products.\nProjects: DevOpsEngineer 695\nEstablished secure CI/CD build pipelines using GitHub Actions and Docker.\n\nDevOpsEngineer 477\nAutomated system configuration and package management using Ansible playbooks.\nEducation: Bachelor of Arts in History\nState University, 2023',
```
